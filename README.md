# temperature-sal-microbes
The repository contains all code generated for the paper "Temperature drives transcriptomic shifts in amphibian skin bacterial communities with consequences for fungal pathogen control". This includes code for all figures and statistical tables associated with the manuscript. Batrachochytrium dendrobatidis (Bd) and Batrachochytrium salamandrivorans (Bsal) are two wildlife diseases causing massive loss of amphibian populations worldwide. While it has been shown that habitat-wide mitigation methods that capitalize on the thermal mismatch between Bd/Bsal and their hosts (e.g., warming the host or environment) and the inherent amphibian microbiome are key factors in disease prevention, they have yet to be studied in conjunction. This study examines the interactive effect of temperature and Bd/Bsal infection on the host microbiome, an essential component of disease prevention. This code examines Alpha and Beta diversity metrics, in addition to Relative Abundance, ANCOMBC analysis, and metatranscriptomic analysis using DESeq2.

# Data 
This data includes Illumina sequencing information processed via Qiime 2. In addition to transcript data generated by Novogene and processed using Bowtie2.
